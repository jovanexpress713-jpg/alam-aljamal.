# ALAM ALJAMAL — عالم الجمال

منصة تجارة إلكترونية عربية قيد التطوير، تتكون من متجر العميل ولوحة إدارة مستقلة وتطبيق Android.

## الحالة الحالية
- تم استيراد الواجهة الحالية من مشروع التصميم.
- بيانات المنتجات الحالية تجريبية للمعاينة فقط.
- لم يتم ربط قاعدة بيانات أو بوابة دفع أو خدمة توصيل خارجية بعد.
- لا يوجد APK إنتاجي حتى يتم بناء التطبيق والتحقق منه.

## التطوير
سيتم تنفيذ العمل على فرع `work/initial-platform` مع إبقاء `main` كفرع تأسيسي.

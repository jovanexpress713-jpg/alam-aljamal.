# ALAM ALJAMAL — متجر واحد موحّد

منظومة تجارة إلكترونية واحدة داخل مستودع واحد: متجر العملاء ولوحة الإدارة وتطبيق Android تشترك في الهوية ومصادر البيانات والـ Backend. لوحة الإدارة جزء من التطبيق نفسه على المسار الداخلي `/admin` وليست مشروعاً أو مستودعاً منفصلاً.

## الهوية
- أسود فحمي + ذهبي فاخر.
- استخدام أيقونة الشعار الزخرفية فقط؛ لا نستخدم الكتابة أو رقم الهاتف الموجودين داخل صورة الشعار.
- العربية RTL افتراضياً، والإنجليزية LTR ضمن خطة التوسعة.

## الوضع الحالي
- واجهة متجر متجاوبة مع البحث والتصنيفات والترتيب والسلة والمفضلة المحلية.
- لوحة إدارة ضمن نفس تطبيق React/Vite وليست مستودعاً مستقلاً.
- المنتجات المعروضة حالياً بيانات توضيحية فقط.
- Backend وSupabase Auth/RLS والطلبات الفعلية والمخزون والدفع والتوصيل وإشعارات الإنتاج لم تُفعّل بعد.
- لا يوجد APK إنتاجي أو نشر إنتاجي مثبت حتى الآن.

## التشغيل
```bash
npm install
npm run dev
npm run build
```

## الإدارة
المسار `/admin` جزء من نفس SPA. قبل إتاحته تجارياً يجب ربط تسجيل دخول إداري وصلاحيات RBAC والتحقق منها في الخادم وRLS؛ إخفاء المسار أو الأزرار ليس حماية.

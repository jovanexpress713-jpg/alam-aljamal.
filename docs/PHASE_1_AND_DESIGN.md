# المرحلة الأولى والثانية — ALAM ALJAMAL

## فحص المستودع
- الفرع المستهدف: `work/initial-platform`.
- فرع `main` محفوظ دون تعديل.
- التقنية الموجودة: React 19 + TypeScript + Vite.
- توجد بداية واجهة مستوردة، إعداد CI، ملف بيئة نموذجي، وترحيل SQL أولي.
- لا يوجد إعداد Supabase فعلي أو أسرار اتصال في المستودع.

## ما أُنجز في هذه الدفعة
- واجهة متجر عربية RTL مستقلة بمقاسات متجاوبة.
- بحث وتصنيف وترتيب المنتجات.
- سلة محلية محفوظة في المتصفح، مع تعديل الكميات والحذف.
- مفضلة محلية محفوظة في المتصفح.
- تنبيه واضح بأن صور ومنتجات العرض تجريبية وليست مخزوناً للبيع.
- لوحة إدارة مستقلة على المسار `/admin`، لا يوجد رابط لها في واجهة العميل.
- لوحة الإدارة تعرض حالة التهيئة بدلاً من اختلاق أرقام مبيعات أو طلبات.

## حدود هذه المرحلة
- السلة والمفضلة محليتان على الجهاز وليستا متزامنتين بين المستخدمين.
- لا يوجد تسجيل دخول حقيقي أو صلاحيات خادم مفعلة بعد.
- لا تُنشأ طلبات فعلية ولا يتم خصم مخزون.
- لا توجد بوابة دفع أو شركة توصيل مرتبطة.
- لوحة الإدارة ليست محمية بالمصادقة حتى يتم ربط Supabase Auth وسياسات RBAC/RLS واختبارها.
- لا يوجد APK أو نشر إنتاجي مثبت في هذه المرحلة.

## التحقق
يجب اعتبار البناء ناجحاً فقط بعد نجاح GitHub Actions على هذا الفرع. لم يتم إجراء اختبار محلي من بيئة التطوير في هذه الدفعة.
